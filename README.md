# Everyday Yoga Fitness Website

A multi-page website created as part of my Software Engineering coursework to practice fundamental web development concepts using semantic HTML5 and core version control workflows.

---

## Project Overview

**Everyday Yoga Fitness** is a multi-page web application designed for a fictional yoga and fitness studio. The primary objective of this project was to construct a fully functional layout using pure semantic HTML5 without external CSS frameworks, focusing on proper page structure, form handling, table layouts, and navigation logic.

---

## Features

* **Home Page (`index.html`):** Landing page featuring a studio introduction, hero media, and quick-action navigation buttons.
* **About Us Page (`aboutus.html`):** Overview of company history, core studio values, and instructor bios with profile photos.
* **Services Page (`services.html`):** Interactive class schedule listing session types, difficulty levels, and monthly fees structured inside an HTML table.
* **Contact Us Page (`contactus.html`):** Contact form with input fields for user inquiries and physical studio location details.
* **Book Now Page (`booknow.html`):** Reservation form allowing users to select a class, choose a session date, and submit custom requests.

Key Learnings
- Semantic HTML Markup: Structuring layouts using <header>, <main>, <section>, <nav>, <aside>, and <footer> tags for clear document structure and accessibility.
- Data Organization: Implementing <table>, <thead>, <tbody>, <tr>, and <td> elements to present class schedules and pricing clearly.
- Form Elements & Validation: Building functional forms using input types (text, email, tel, date) and dropdown selection menus.
- Document Linking: Connecting local HTML files across pages using relative paths.
- Version Control Workflows: Managing repositories and code iterations with Git Bash commands (git add, git commit, git push).
