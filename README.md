Project Name: Everyday Yoga Fitness Website

This is my Web Development class project where I built a multi-page website for a Yoga and Fitness Studio named- Everyday Yoga Fitness. 

The main goal of this project was to practice using semantic HTML5 elements, creating forms, building tables, linking images, and connecting pages together using pure HTML without external frameworks.


Features Included

Home Page (index.html): Landing page with studio introduction and navigation buttons.
About Us Page (aboutus.html): Information about our company, core values, and instructor bios with profile photos.
Services Page (services.html): A detailed timetable showing classes, schedules, levels, and monthly fees in an HTML table.
Contact Us Page (contactus.html): A complete contact form for user inquiries and studio location details.
Book Now Page (booknow.html): A reservation form where users can select a class, pick a date, and leave special notes.

How to Run locally
Clone this repository to your local computer:

Bash
git clone https://github.com/MichaelMulwaM/everydayyogafitness
Navigate into the project folder:

Bash
cd everyday-yoga-fitness
Double-click index.html to open the website in any browser (Chrome, Edge, Firefox, or Safari).

What I Learned
How to structure web pages using HTML tags like <header>, <main>, <section>, <nav>, and <footer>.

How to create tables with <thead>, <tbody>, and <tr> for organizing data.

Creating forms using input tags (text, email, tel, and date).

Connecting multiple local HTML files together using relative links (<a href="...">).

Basic terminal and Git commands for version control (git add, git commit, git push).
